# Icon and Logo TODO

The Home Assistant addon requires two image files:

## Required Files

1. **icon.png** - Small icon displayed in the addon store

   - Recommended size: 256x256 pixels
   - Format: PNG with transparency

2. **logo.png** - Larger logo for addon details page

   - Recommended size: 512x512 pixels
   - Format: PNG with transparency

## Creating the Images

You can create these images using:

- Design tools (Figma, Inkscape, GIMP, etc.)
- AI image generators
- Hire a designer

## Placement

Once created, place both files in this directory (`fluxion/`):

```
fluxion/
├── icon.png
├── logo.png
├── config.yaml
├── build.yaml
├── Dockerfile
├── DOCS.md
└── ...
```

## Tips

- Use simple, recognizable imagery related to solar/energy
- Ensure good contrast for visibility on both light and dark backgrounds
- Keep the design clean and professional
- Consider using your company/project branding colors
